# Support

## How to Get Help

This is a sample code repository provided as a demonstration of Responsible AI on AWS. It is not an officially supported AWS product.

### For questions about this sample:

- Open a [GitHub Issue](../../issues) with details about your question or problem
- Include your environment (AWS region, Python version, Terraform version)
- Include any error messages or logs

### For AWS service-specific questions:

- [AWS Documentation](https://docs.aws.amazon.com/)
- [AWS re:Post](https://repost.aws/)
- [AWS Support](https://aws.amazon.com/support/) (for customers with support plans)

### For security issues:

Please see [SECURITY.md](SECURITY.md) for reporting security vulnerabilities. Do not open a public issue for security concerns.

## Scope of Support

This sample is provided "as-is" under the MIT-0 license. We welcome bug reports and feature requests via GitHub Issues, but there is no guaranteed response time or resolution commitment.
